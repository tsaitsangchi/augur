**augur 不以交付物定義**。定義句＝憲法永恆條款（`AUGUR-MC v1.6 §1.1` 原文）：*「Augur exists to faithfully represent reality through persistent identity and traceable evidence, enabling trustworthy intelligence.」*——§1.2 明文「智慧不是第一目的」，是世界被正確表徵後自然長出的能力。

**世界建構八層（次序不可亂，缺前層則後層必壞）**：L0 憲法（鑄詞十一定義／EV.1–12 演化鏈／六器官／F1–F6 六禁令）→ L1 世界模型（權威三分：來源只對其回傳位元組有權威、世界結構由規格宣告、系統儲存只是「唯一系統記錄」非真相）→ L2 本體論（五範疇＋同一性判準三要件；判準只制定不生效）→ L3 身分（鑄造／採認／claim／生命週期；ID.41 任一時點該編號指向誰必可重建）→ L4 知識（五元組＋單一信度格＋KS.73 NoLaundering 信任不可洗白＋不朽律＋反自我背書）→ L5 認知（推理產物永遠只是候選；L5.2 引用鏈必終止於觀測或明示假設）→ L6 行動（問責六元組；授權鏈根必為活人；L6.17 OCV 單向棘輪）→ L7 基礎設施（「上層不變式在此只剩『誰持有能撤銷它的權限』一個問題」；登錄簿模式＋刪名測試＋合規須可執行測試證明）。

**一條路（唯一合法成長路徑）**：候選 →（證據通道：可證偽／樣本外／**實效終審**）→ 人類授權門 → 晉升或**判死留檔** → 後果回流成新觀測 → 下一圈。**八行走者無特權通道**：①認知候選 ②人類原典 ③思想原理 ④AI 能力宣稱 ⑤模擬方法 ⑥模型／隊伍 ⑦迭代程序本身 ⑧**法律自己**（修憲亦適用 §8.5(a) 證據先於結論）。

**域中立（憲法自證，非我的詮釋）**：P1.E1 觀測通道開放列舉「包括但不限於 ERP／MES／Sensor／Document／External Knowledge」；P3.W2 把金融工具與工廠、機器並列為例示；WM.52 新域＝加一份 Domain Profile 附錄、**母法一字不動**；A.34 連「最小時間粒度」都標為各域自行宣告、非全系統不變式。**口號：法屬世界、足跡屬域。**

**自反性法源鏈（四條自進化線之法源，非工程巧思）**：MC §2.1（Augur 自身為 Reality 中可觀測實體）→ WM.26 → ONT **T.28 SelfReflexiveType** → ID.11 → KS.75–77（反自我背書三條）→ L6.4／L6.19（self-reported 標記）→ L7.5（起草 Agent 登錄限制自己之 kill-switch）→ MC §8.1（Agent 不得參與修憲與解釋）。合起來：**能拷問自己、不能偷改自己、不能靠引用自己變可信**。

**Why**：2026-07-30 hugo 五度校正報告書框架後定案（①補方向轉向②補市場模擬自進化③補知識哲學自進化④補 L0-L7 概念層⑤反轉定義：台股只是具象）；再追加三則：不要在憲章強調股市／「日線是一個域的選擇」仍限於股市／所有具象走同一條路不該分域。**以交付物（預測台股）定義系統是錯的**，且靈魂登錄為 Layer 1 而 WM.7 明令「世界模型必須優先描述 Reality、不得優先適配資料來源」——該疑義已列 [[augur-treaty-alignment-tracks]] 乙-1 呈裁。

**How to apply**：寫任何報告／計畫／對外敘述時，先問「這句是在描述世界的法，還是某個域的足跡？」——法用域中立語言，足跡標明所屬域。新增任何機制前問「它是哪一類行走者？走的是同一條路嗎？」不同的路＝特權通道＝違核心。全文詳 `reports/augur_plain_language_full_report_20260730.md`（v11）。
