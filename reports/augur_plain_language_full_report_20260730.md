## 一、這是什麼（先把定義說對）

Augur **不是一套預測台股的系統**。它是**一個從零建構出來的世界**：一部憲法先鑄造出「談論世界所需的最少詞彙」與「什麼算合法的一步」，然後七層規格依次把這個世界立起來——世界裡有什麼（L1）、東西分什麼類（L2）、每一個是誰（L3）、關於它們的說法怎樣才算可信（L4）、這個世界怎麼思考（L5）、誰有權伸手改變現實（L6）、這一切棲身在哪塊鐵上（L7）。

台股模擬、本地 AI 自進化、know-how 自進化、股市模擬自進化——**全部都只是這個世界在表面長出的具象化結果**。台灣證券市場是憲章明文的「第一域」，不是唯一域：同一個世界今天長出台股，明天可以長出任何能被誠實觀測的領域，而底下八層一個字都不用改。這就是為什麼前身專案（程式、資料、模型）死透了，這個世界卻能 clean-room 重生——**會死的是實作，不死的是世界的建構法**。

一句話定義：**Augur 是一個「可被誠實表徵、可被歸責地改變」的世界，目前以台灣市場為第一個具象域。**

## 二、創世紀：這個世界如何從零開始建構（L0→L7）

以下每一層都回答三個問題：它建構什麼、為什麼必須排在這個位置、缺了它世界會怎麼壞掉。全部取自規格原文，不是我的印象。

### 第零步・L0 憲法：在什麼都沒有的地方，先立法（AUGUR-MC v1.6）

創世的第一動作不是寫程式、不是建資料庫，是**鑄詞**。憲法 §2 用十一個定義把「世界—看見世界—描述世界—相信世界—改變世界」這條路上的每個站名釘死：Reality（世界本身，不因被系統記錄才存在）、Observation（一次帶來源帶時間戳的量測，外界進入系統的唯一入口）、Representation（可追溯的結構化描述）、Identity（唯一且持續的指稱）、Evidence 與 Knowledge（互為表裡：證據是被引來支持知識的觀測，知識是有身分、有來源、有證據、有信心值、可被推翻的斷言）、Action 與 Agent（被授權改變現實的事件與程序）……並附一條元規則：**下層文件只准細化這些詞、不准重新定義**——防的是每一層私造詞彙然後沉默地互相矛盾。

第二動作是**排序**。§4 的 EV.1–EV.12 把這些詞排成唯一合法的演化鏈：現實被觀測 → 觀測凝成表徵 → 表徵繫上身分 → 身分撐起證據 → 證據撐起知識 → 知識推動推理與規劃 → 規劃**過人類授權門**才成為行動 → 行動改變現實後必須被重新觀測回流。鏈上不准跳站。而且它區分兩個迴路：**因果迴路**（唯有 Action 能改變 Reality）與**認知迴路**（學習、回饋只改系統內的表徵——模型變聰明不算改變世界，而且學到的東西仍要走證據通道才准升格成知識，不准直寫）。

第三動作是**預告器官**。§5 宣告任何未來系統都必須長出六個器官：權威世界狀態帳本（只增不刪、筆筆有出處）、關係表徵、語意記憶、理解引擎、行動層、受控對外介面。

第四動作是**封死歧路**。§6 的六條禁令 F1–F6，每條都是一種「世界會先天畸形」的建造順序：禁資料先行（資料表的結構不是世界的結構）、禁模型先行（模型只是工具）、禁 Agent 先行（Agent 會放大錯誤的世界理解）、禁無身分無來源的知識、禁答不出「為什麼」的智慧、禁答不出「誰發起、誰授權」的行動。

最上面壓著一句動不了的永恆條款（原文照錄）：*「Augur exists to faithfully represent reality through persistent identity and traceable evidence, enabling trustworthy intelligence.」*——先忠實表徵現實，然後才配談智慧。五大原則各是一個先後裁定：

| 原則 | 白話 | 它否決什麼 |
|---|---|---|
| **P1 真實優先** | 世界怎樣就怎樣記 | 「補個合理值」「這筆先跳過」 |
| **P2 表徵先於智能** | 先描好世界才准聰明 | 「模型直接吃生資料自己想辦法」 |
| **P3 身分先於知識** | 先確定說的是誰 | 張冠李戴 |
| **P4 證據先於結論** | 結論從證據長出來 | 「我覺得」「大家都知道」 |
| **P5 問責先於行動** | 每個動作有人負責 | AI 自我授權 |

**缺了 L0 會怎樣**：下游每層各自私造定義——資料層把「有一筆 row」當成「知道一件事」，模型層把「模型輸出了」當成「有理由相信」，Agent 層把「程式跑了」當成「有人授權過」。三種畸形，正是 F1/F2/F3 各自禁止的世界。

### 第一步・L1 世界模型：宣告世界由什麼構成

在還沒有任何資料庫與程式之前，先宣告：世界裡有哪些東西（實體、事件、狀態、關係、量）、什麼算「事實」、事實怎麼隨時間變。最鋒利的一刀是**權威三分**：外部來源（如 FinMind）只對「它當次回傳的那些位元組」有權威；「世界裡存在什麼」由規格宣告；系統裡存的權威表徵只是「唯一系統記錄」，**永遠不是真相本身**。每筆表徵必須綁一個「指涉對象」、必須留來源槽與不確定性槽；每個世界事實只有一個權威表徵，但可以有多條觀測通道供應，**通道打架時證據並存標記衝突，不准誰後寫誰贏**；「證據不足」是合法狀態。另有雙時間性（何時為真 vs 系統何時得知）、與一套**永久標記體系**（合成的、假設的、已被取代的、有衝突的……標記一經附著，隨一切轉引與加工永存不滅）。

台股具象：「個股名冊的成員資格是時間的函數」（不准拿今天的名單充當歷史名單——倖存者偏差禁令）；「原始成交價與還原價是同一個世界事實的兩條觀測通道」；「新台幣匯率是一個世界概念，FinMind 與 FRED 只是它的兩條通道」；預測任務閉集只有兩項——橫斷面相對強弱、經預註冊門的方向機率——**逐日價格點位永久除外**。

**缺了 L1 會怎樣**：世界結構被供應商的表結構反推定義、「API 即權威」膨脹成世界真相、每接一個新來源就多一套私有語義互相稀釋——洩漏、倖存者偏差、靜默覆寫全部變成無法可判的灰域。

### 第二步・L2 本體論：給萬物分類，寫下「怎樣算同一個」

L1 說「世界上有股票這回事」；L2 接著說「股票是哪一類、兩檔股票何時算同一檔、台積電是個體而『上市普通股』是類別」。一切型別上溯終止於五範疇（實體／事件／狀態／關係／量）；每個型別的定義三要件缺一即無效：上位範疇、**同一性判準**（「同一 iff 某可判定條件」，例如證券同一 iff 同一發行人×同一工具類×同一發行序、且不跨下市重上市邊界）、個體／類別繫結語義。兩個關鍵區分：**外部識別碼不是身分**（股票代碼、ISIN 只是指涉線索，不准靠「欄位字串相等」直接 join 推定同一）；**公司與股票是兩個實體**（發行人更名借殼不改公司身分，但可能改其所發證券的身分）。而且 L2 只「制定」判準文本、刻意不讓它生效——生效權在下一層。

**缺了 L2 會怎樣**：「兩個通道講的是不是同一個東西」永遠答不出來；台股指數與個股共用代碼空間、代碼會被重用——沒有判準文本，後面的身分層無物可依。

### 第三步・L3 身分系統：給每個個體發永久身分證

L3 做四件事：**鑄造**系統自己的識別碼（永不刪除、永不重用；外部代碼只能當線索）；**採認**L2 制定的判準（一個具名、附證據、可追溯的採認動作——採認前一切引用保守視為「未解析」，不准升級成知識）；把「這兩個識別碼指同一個東西」變成**一級知識斷言**（要帶判準引用＋證據＋信心槽，矛盾斷言並存不覆蓋）；管**生命週期**（合併、下市、重上市、墓碑……每件事都是必附證據的事件，任何時點「這枚身分證當時指向誰」必須答得出來）。屬性也綁時間：**不准用今天的產業分類回頭判定歷史**。

台股具象直接對準四個真實審計傷口：台股代號在公司下市後會被回收給另一家公司——若拿代號當身分，兩家公司的歷史會被縫成一條假時間序；L3 規定同一代號再現名冊必須觸發紅旗、解析成不同個體。證券／指數／FRED 序列的判準已經人簽裁決採認生效；發行人判準仍待採認、相關引用維持保守未解析（誠實帳）。

**缺了 L3 會怎樣**：直接重演系統成立前的四樁審計事故——裸字串成了事實身分、代號重用縫合假歷史、跨來源同一性靠各處 regex 自由心證、今天的分類污染歷史回測（＝偷看未來）。

### 第四步・L4 知識系統：讓「說法」成為可信、可追溯、可失效、可回放的物件

前三層備好了「有什麼、哪一類、是誰」，L4 把「關於它們的說法」升格成嚴格物件：任何一條知識必須是**五元組**——誰說的、何時有效／何時得知、關於哪個個體、憑什麼證據、多可信——缺一即違憲。在此之上鑄造整套「信任的物理學」：全系統唯一的**信度格**（不足＜低＜中＜強＜確定，所有信心表述必須映入同一把尺才能互比）；**信任守恆律**（結論的信度不得高於前提鏈最弱環節——證據鏈上洗不白）；**時間機器**（每張知識表宣告 as-of 能力等級，「直接覆寫」是禁止型態；已對人呈現的結論不得靜默重寫，任何過去時刻「系統當時相信什麼」都可重建）；**不朽律**（知識與證據只能標記失效，永不刪除）；**矛盾共存律**；**信任階級**（獨立實證＞文獻＞模型輸出＞自我陳述——AI 合成天生低階）。

台股具象：預測表曾被 DELETE+INSERT 覆寫——正是禁止型態，於是有了「誠實觸發器」（資料庫層拒絕 DELETE、UPDATE 要通行證）；來源歷史值被改時必須先快照舊值建取代關係，快照失敗禁止寫入；「系統曾對人出過什麼建議」永遠可回放。

**缺了 L4 會怎樣**：推理引擎拿著三套互不相通的信心物件各說各話、模型輸出轉幾手就洗白成「事實」、預測被靜默改寫成事後諸葛——**系統會流暢地運作，並流暢地自欺**。

### 第五步・L5 認知核心：允許世界思考——但只准誠實地想

前四層造好「知道」，L5 造「想」——但不是任意的頭腦，是**被憲法約束的推理引擎**。規則：任何推理產物（推論、模型輸出、比對結果）都只是**候選斷言**，不是真理；每個結論必須能沿證據鏈追溯回「對現實的觀測」或「明白宣告的假設」兩個終點，中間不准繞圈自證；信心沿推理鏈只能守住最弱環節；假設在**樣本外驗證＋經濟裁決**通過前永遠掛「未證」；每個結論欠世界一份能落到個體層的解釋（為什麼是這一支、憑什麼、多可信）；AI 模型只是工具，輸出永遠帶合成標記、信任有天花板；推理只准用時點 T 以前就存在的資訊。

台股具象：「康波週期」「80/20」這類思想只能生假說，過預註冊門＋樣本外＋經濟裁決才准入徵，思想裡的魔數不准寫進特徵公式；方向模型全家族二次證偽後凍結、不開 v3——正是「無證不升級、二次證偽封鎖」的活案例。

**缺了 L5 會怎樣**：模型輸出可以自抬信心、假設偷偷變事實、回測偷看未來——「智能」變成無證據的自說自話，正是禁令 F5 要防的世界。

### 第六步・L6 行動治理：給世界一隻被拴好的手

前五層的世界只會「知道」，還沒有能伸出去改變現實的手。L6 建構的就是這隻**被鎖鏈拴好的手**：任何要改變現實的動作，出手前必須先物化成完整問責記錄（誰發起、誰授權、憑什麼知識、預期什麼、事後實際造成什麼）；**每條授權鏈往上追必須終止於一個活生生的人類**（根節點不得是 Agent、不得循環）；「計畫」與「執行」之間立著強制關卡（人類授權門）；動作按「可逆性×影響」分五級風險，越高要求越嚴（最高級要事前雙人獨立核准）；人類監督能力被造成一把可機器計算的尺、釘上**單向棘輪**——任何改動只准讓人類的否決能力不降；最後裝熔斷器——依據的知識被推翻、實際效果偏離預期太多，受污染的行動一律停。

台股具象：「AI 顧問不是自動駕駛」的全部機器化——治理提案三表三鎖必須 hugo 親簽才生效（首案 v1 被退回、v2 人簽通過）；promoted_by／approved_by 一律人親跑寫入、AI 不得代打（曾實犯一次、記為教訓自陳留檔——恰是規格所防的自我交易）；擂台計分板誠實化、未過門的數字不得呈現。

**缺了 L6 會怎樣**：跳過它先蓋 Agent 框架＝元憲章 F3 死罪——一個能行動卻無問責結構的系統，每個動作都是無主行動，**而且事後補鎖永遠補不齊**。所以開機序列明定：先建立人類根授權與關卡，才准啟動任何 Agent。

### 第七步・L7 基礎設施：讓概念變成鐵

最後一層把前面全部只用文字懸置的東西**真正造出來**：上層說「證據不可滅失」，到這裡才變成 PostgreSQL 的只增不刪觸發器；上層說「人類隨時可否決」，到這裡才變成 1 秒內必須停下的 kill-switch 五層降級序（軟體閘→暫停計畫→殺程序→斷網撤憑證→切電源）。手法是**登錄簿模式**：規範永遠不指名產品（刪掉所有產品名後條款內涵必須不變），具體選型只是登錄簿裡可隨時替換的現行值——所以資料庫換掉、模型換掉，世界不動。因為其下再無一層，所有上層「留待下層」的帳在此結清：做不到的不准沉默，必須登錄為待決並走保守預設（「受控介面未登錄→全系統不得執行任何行動」）。最誠實的一條是它的自我意識：**本規格由 Agent 起草，而內容正是限制起草者的物理機制**——所以一切分離與拒絕必須用可執行測試證明，文件宣稱不算數。

**缺了 L7 會怎樣**：上層一切不變式只是紙上義務——只增不刪若可被應用角色自己解除、kill-switch 若跑在被控 Agent 的容器裡，「不可刪除」「人類可否決」在憲章意義上根本不成立。

### 三條讓階梯不塌的規則＋世界開始轉動

**上層約束下層**（下層牴觸上層的部分直接無效）；**概念層獨立性**（憲法 §0.6(b) 明文：L1–L4 不得引用執行層構件來定義自己——「專案退化成只有實作層」這件事本身就是違憲）；**十年穩定**（概念層設計成在工具、模型、語言全部換血後原封活著）。

八層立畢，世界開始轉動，走的就是 L0 排好的那條鏈：**觀測 → 表徵 → 身分 → 證據 → 知識 → 推理 → 規劃 → 人類授權門 → 行動 → 改變現實 → 重新觀測回流**。兩個迴路各行其道：因果迴路改變世界，認知迴路只改變系統對世界的理解——而理解的每次升級，仍要走證據通道受審。

## 三、具象化：這個世界目前長出的表面

以下每條線都不是「系統的功能」，是**世界在第一域（台灣證券市場）與自身之上長出的具象**。每條線後面標注它主要是哪幾層的化身。

**① 選股主線（相對強弱）〔L1 表徵＋L5 推理＋L4 經濟裁決〕**——**已證實**：扣成本後淨 Sharpe ~1.2-1.5、遠勝基準 0.83（21 個月切面、走著瞧、同尺自證）。生產特徵集剛從 1 顆成長到 2 顆（「借券費率」過完四道關卡）。**願望**：歷史回測已證，live 賺錢未證。

**② 個股方向走勢〔L5「假設未證即未證」＋L6 誠實輸出契約的化身〕**——07-11 已轉向，三塊講才準確：
- **「預測」宣稱＝已判死**：自家方向模型全家族兩次證偽、永不翻案；逐日價格點位當「預測」輸出＝永久禁止（L1 就把它排除在預測任務閉集外）。
- **「走勢」需求＝活著的產品形態：蒙地卡羅模擬情境**——唯一合法答法：拿該股自己的歷史日報酬純重抽（一萬條路徑、不摻模型傾向），畫分位錐與終值分布。**四道鎖**保證它永遠不被當成預測：浮水印「模擬非預測」、聊天機器人不准覆述模擬數字、資料庫只存規格與摘要、四鎖本身入憲。
- **「宣稱升級」路＝arena 真未來賭注＋重演軌**：live 才 2 個有效樣本日（需 60，約十月底）。**本週突破**：你一句「不用等新資料、as-of 回放歷史就好」催生重演軌——嚴格「只看當天以前」把 11.5 年當賭注重放，一夜 2,798 個樣本日。首批判決：純動能隊、蒙地卡羅隊雙雙判死（門檻預先凍結、判死留檔）。這條重演軌本身就是 L4 時間機器（任何過去時刻系統知道什麼可重建）的直接應用。

**③ 程序重演（最深的具象）〔L4 時間機器用在世界自己身上〕**——你的第二個點子：不只重放模型，**重放「挑特徵的程序」本身**——回到 2018 年每個月，用當時可知的資料跑一遍今天的挑選流程，看這套流程的適應力是否逐期賺到超額。引擎已建好、密網格（102 個月份切面）正式掃描中。**願望**：增益是否顯著，門檻已凍結、資料未到。

**④ 本地 AI 自我進化〔認知迴路的化身：改的是表徵不是世界，升格仍要過證據通道〕**——小模型（qwen3-4b）當顧問引擎，提示包進化過四代——**誠實結論：全部退役**（新量尺證明舊高分是格式取巧＋捏造）。現在賭「能力格」新量尺：0.618/0.583（超過 0.5 地板）——若重跑兩輪站住，就是專案史上第一份真能力證據，並解鎖 1.7b 微調的決策。

**⑤ 知識與哲學庫〔L4 知識五元組＋「AI 永不寫入知識本身」的化身〕**——幾十萬句經典與論文原文（公版／CC／自有私檔三軌，AI 生成禁入庫）。來源審批半自動化：人簽規則一次、機器在規則內批（本週 24 倉自動入池、七項檢查筆筆留帳）——這正是 L6「人簽規則、機器執行」形態的活體。

**⑥ 治理與防呆基建〔L6＋L7 的化身〕**——憲法＋領域憲章 v1.49.0＋二十條原則。本週新增：生產特徵表誠實閘（起因：一次無帳寫入，你定性「我搬的」後補齊全鏈記帳並上鎖＝L4 不朽律的又一根鐵條）、全機 LLM 車道統一排隊。

**⑦ 市場模擬引擎的自我迭代〔L5「先立規則再看數據」用在模擬方法自己身上〕**——模擬方法庫本身是一條在進化的線，進化方式和選股特徵一模一樣：先凍結判讀規則、再讓方法同場競技。
- **第一輪四法對照（已結案）**：四種模擬法在同一凍結資料上比「最大回撤估得像不像」，判讀規則跑前凍結。結果觸發預註冊的「跨數量級」分支：天真法把「腰斬兩成」機率低估一個數量級——依規則取保守值入風險畫像：**持有 60 天破 −20% 機率＝5.6%、120 天破 −25%＝2.4%**。白話：市場會連著跌，假裝每天獨立就把尾巴想得太美。
- **第二輪已拍板在隊列**：episode 五窗（金融海嘯／疫情崩盤逐窗檢驗）＋三個進階法（copula-t、EVT、跨市場類比），參數 commit 即凍結。
- **模擬也要上擂台受審**：蒙地卡羅隊在重演軌的判決是**死**（方向 Brier 比恆猜還差）。這個判死恰恰證明四鎖邊界劃對了：**模擬擅長畫風險的形狀，不擅長猜方向**——所以它的產品位置是風險畫像，不是預測。
- **三個尺度同一思想**：模擬市場路徑（MC 情境）、模擬模型的歷史（重演軌）、模擬迭代程序本身（程序重演）——整個世界正在變成一台「用歷史反覆拷問自己」的機器。

**⑦′ 燃料迴圈（RAWEVO）**——①線的特徵彈藥從哪來？每週六自動掃原始表找「欄位對異常相關」→ 假說提示 → 過你的閘 → 掛哲學原理與方向 → 派生候選 → 四道關卡。本週首次全線貫通（10 則提示 → 7 則入映射 → 7 顆交互候選已算值待審）——「資料自己提出假說」的那一環，而假說仍要走 L5 的證據通道。

**⑧ 知識庫的自我迭代〔KH1→KH10：認知迴路在知識域的十層樓梯〕**——五個迴圈同時在轉：
- **求知迴圈**：每六小時掃描知識缺口、自動生成新檢索問題丟給夜鏈收割（範圍鎖死在你核過的領域，新領域永遠要你拍板）。
- **十層智慧線 KH1→KH10**：**KH1 資格**（有沒有資格進系統）→ **KH2 預審輔助**（AI 掃旗標但不裁）→ **KH3 終態就緒**（推到可作答或誠實標「被授權擋住」）→ **KH4 檢索作答基線**（可逐字引用、答不出誠實說——最低可用閉環，已閉合）→ **KH5 擴軸** → **KH6 交互投影**（本週三輪真探測）→ **KH7 對抗可答性**（首輪 S1 已跑）→ **KH8 證據權衡** → **KH9 合成回放** → **KH10 進化治理**（學習進閉環，最終權威永遠在人）。本週：KH10 自動准入水印入憲（原文過硬閘先進門、逐層升格、深層沒過不回滾淺層——寧可庫裡有「還沒讀熟的書」，不可有「被 AI 改寫過的書」）；同時立了六條「明確不做」。
- **來源池自動擴張**（前述⑤）；**哲學映射跨域進化**（孫子「知彼知己」→ 機構籌碼代理資訊優勢 → 掛到特徵讓數據裁決——哲學是假說產生器，不是權威）；**顧問自我探針**（拒答記錄自動變成下一輪的探針候選——答不出的地方就是下一輪進化的地方）。

五個迴圈共用同一條 L0 級底線：**AI 永遠不能寫入「知識本身」**——它只能搬運、切分、標記、檢索原文，所以庫再怎麼自我迭代，裡面躺的永遠是人類寫的原文。

## 四、為什麼規矩這麼多（三個敵人的故事）

前身專案死於三件事：**假資料**（API 沒回的值自己補）、**偷看未來**（用公告前的財報回測）、**自我欺騙**（指標挑好看的講）。用第二章的語言重講一遍：假資料違 P1、偷看未來違 L4 的時間機器、自我欺騙違 L5 的證據鏈——三敵人不是三條工作守則，是**對世界建構法的三種背叛**。所以重建時不靠自律、靠機關：觸發器擋無帳寫入、判準先凍結再看資料、每個「確立」宣稱過預註冊統計門。這三天這些機關實際擋下我七、八次失誤，它們不是裝飾。

## 五、這三天發生了什麼（一段話版）

你的兩個提問把「等三個月日曆」變成「一夜之間」：模型重演軌（11.5 年 ×4 隊 ×417 萬筆結算）與程序重演軌雙雙落地；期間機關與人互相接住了至少十次失誤——六發「不同尺互比」陷阱全在便宜處攔下、兩次沒實測就推版被自己抓包記過、一次無帳寫入被鑑識出來後反過來補了根因鎖。**這個世界變強的方式不是模型變聰明，是「說錯話變得越來越難」。**
