## 一、標的條文（逐字）

> **P2.E1**：禁止 AI 直接從 raw data 建立永久性 Knowledge。所有 AI 產物必須經標準鏈（§4 之節選 EV.2–EV.6）：
> `Observation → Representation → Identity → Evidence → Knowledge`

**性質辨明（事實，非判斷）**：本條為**程序要求**（AI 產物須走該鏈），**非內容禁令**（未禁任何特定內容入庫）。

## 二、最重之連帶後果：七份 live 規格之形式充分性

P2.E1 被 **7 份 live 規格之 `WM.44` 逐條覆蓋矩陣逐一具名列入**，而該矩陣**即形式充分性、即生效要件**：

| 規格 | P2.E1 之落點 | 位置 |
|---|---|---|
| `WORLD-MODEL` | `WM.18`（候選斷言之地位）`refines`；`WM.24` 承接；MC-21／MC-24 矩陣列 | :204／:715／:718／:813 |
| `ONTOLOGY` | 標「不觸及（附理由）」＋所引條款清單 | :434／:537／:596 |
| `IDENTITY` | `ID.50`、`ID.30(c)` **承接**；CS.1-P2 引 | :440／:727 |
| `KNOWLEDGE-SYSTEM` | `KS.20`、`KS.77` **承接**；CS.1-P2 引 | :695／:1014 |
| `COGNITIVE-KERNEL` | P2 家族矩陣列；CS.1-P2 引 P2.E1／E2／W2 | :299／:481 |
| `AGENT-RUNTIME` | P2 家族矩陣列 | :355 |
| `INFRASTRUCTURE` | `L7.48(c)`（入向 Observation 化）**carries** | :482／:816 |

**後果（機械可推）**：條款一經刪除，七份規格之覆蓋清單各出現一個**指向已不存在條款之具名列**。依 `WM.44`「任一條款無對應且無明記者，聲明不完整」之同理，清單列了一個不存在之條款，該清單即失真 → **七層之形式充分性同時帶瑕疵**，除非同批更新七份矩陣。

- `META-CONSTITUTION.md:650` Appendix 之術語更正記錄具名 P2.E1（**史述，依 v1.51.0 通則一應凍結不動**）

## 三、刪除之實際效果（重疊分析）

**同一禁止內容之其餘條款（刪 E1 後仍在）**：

| 條款 | 逐字要旨 | 是否涵蓋 E1 之核心 |
|---|---|---|
| **P2.E2** | 「Model output **不得未經 Evidence 通道**（§2.11），直接成為權威 World Representation 或 Knowledge」 | **是**——E1 之核心禁止（AI 產物直接成為權威知識）由 E2 保留 |
| **P2.E3** | Agent 不得繞過 Evidence 通道將意圖／預期／未證實結果直接寫入世界表徵；自我陳述須永久攜 self-reported 標記 | 是（Agent 側） |
| **P4.E7** | 高風險結論不得僅以系統自身產出為據 | 是（獨立性側） |
| `KS.21`／`KS.74`–`KS.77` | AI 合成證據之永久標記、信任階級天花板、獨立性定義（來源鏈遞迴不含本系統產物） | 是（信度側） |
