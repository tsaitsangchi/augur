## 二、逐行排查結論

**(1) 無字面反向 bug**：`y_tr=(fwd>0)`（漲=1）→ `predict_proba[:,1]`＝P(漲) → isotonic 校準 → 回傳 p_up。全鏈方向一致，無 sign flip、無 label 顛倒。

**(2) 過度自信有明確機械來源（機制定位＝CONFIRMED at code level）**：
- `IsotonicRegression(y_min=0, y_max=1, out_of_bounds="clip")`——isotonic 可輸出**恰好 0.0/1.0**；三 seed 平均後產生 0.9896 這類值（如 (1.0+1.0+0.969)/3）完全相容。
- 校準集=`X[cut:]`、`cut=int(len(X)*0.85)`——而 X 是**逐股堆疊**（per-stock append 後 vstack），85/15 切的是「後 15% 的股票」非「後 15% 的時間」：校準只見特定股票子集，尾端 bin 樣本極少→isotonic 尾部被外推釘死在 0/1。**p_up=0.9896 的過度自信尾＝isotonic 尾部裁剪 × 逐股切分校準集之合成品**，非資料錯誤。

**(3) 反排序（AUC<0.5）在 code 中無病因**：特徵＝1d/5d/20d 動能＋20d vol，HistGBM 自由學非單調映射。首批是崩盤後回彈的均值回歸週——動能連續性假設整週反向，**與「momentum_20 同週 balanced acc 全場最高」不矛盾**（兩者特徵映射不同）。反排序目前的最誠實定位＝**1 個 cluster 的觀察**，不是 code bug 的證據。

**(4) 附帶觀察（非本案病灶、記錄備查）**：`early_stopping=True` 之內部驗證切分是隨機的（時間混切）——只影響訓練窗內的 early-stop 判準，不構成對 arena 標籤的前視；`cut` 切分未 shuffle，校準子集偏向 dict 尾端股票。
