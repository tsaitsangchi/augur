## 一句話

> **Augur 是一套只用真實資料、誠實預測台股的系統。**

從 FinMind / FRED 抓進**可溯源的日級資料** → 算成特徵 → 選出**資料乾淨的核心股** → 訓練模型預測未來一段期間（週/月/季/年）的相對強弱 → 以 **walk-forward 誠實驗證**。

## 名字的意思

**augur** = 古羅馬的「觀兆者」，讀真實的徵兆來預言未來。

- 本系統的「兆」= 真實 API 資料。
- 本系統的「預言」= 機率 / 分數預測。
- **只讀真兆，不造假兆。** 這就是系統的命。

## 它預測什麼

- **標的**：台灣上市櫃個股。
- **任務**：給定一個 as-of 日期，預測各股未來 H 日的**相對強弱**（橫斷面排序——比的是「誰相對強」），據此選出 top-N。H 可週 / 月 / 季 / 年多尺度。 **預言機軸〔v1.6.0;v1.7.0 增輸出契約;v1.8.0 升格〕**:亦預測未來 H 日(日曆 30/60/120 天對映)之**絕對方向機率**(漲或跌的機率,附歷史 OOS 準確率),個股+top3/top5;及日粒度方向機率。**輸出契約三產物〔v1.7.0;v1.8.0 ③升格〕**=①方向機率 %、②方向準確率 %(horizon 級 OOS 命中率,非單股保證)、③**期望報酬率**(**幅度級產物〔v1.8.0〕**:得逐股呈現——由 horizon 級命中率×該股已實現波幅−成本導出、或導自經濟終關回測;與經濟裁決同源硬綁、假設揭露硬綁、非保證)。**原不可違反句「不是預測絕對漲跌幅」已依用戶三度堅持刪除〔v1.8.0〕**——AI 勸阻與用戶堅持雙留痕於憲章 v1.45.0 該條;**不受本次修訂影響之鎖**:逐日價格點位/路徑永久除外、GATE 唯一產生路、單股準確率宣稱仍禁、三敵零容忍(代表性列舉;完整鎖清單 SSOT=憲章**現行版**輸出契約條〔v1.50.0；原釘 v1.45.0 已 SUPERSEDED——**指針不得釘死於史料版**，2026-07-30 機械軌更正〕)。**唯經預註冊可證偽實驗過 GATE 者才成為產品輸出**;未過即判死留檔——預言機的誠實不在「都答對」,在「說得出自己多常對」。
- **產物**：每股的分數 / 機率 → 選股清單，並附**可信度**（walk-forward IC、Effective-t、勝率）。
- **它不是**：明牌產生器、保證獲利、**價格點位神算**。逐日**方向機率**屬 D 軌可證偽實驗;**逐日價格點位、價格路徑、目標價**永久不是本系統的預測產物(路徑唯以「模擬非預測」之蒙地卡羅情境呈現)。**〔v1.9.0 閉集對齊：原列舉漏「目標價」,而大憲章 L137 與 `AUGUR-WM v1.0 §A.38` 皆含之——三檔閉集不一致等於留了可鑽之口,故補齊。E[r] 界線：E[r] 為 horizon 級方向命中率×已實現波幅−成本之聚合換算,**不得反算或呈現為個股目標價／價格點位**;呈現粒度上限＝報酬率百分比。幅度級 E[r] 在 L1 任務閉集之模態定性是否須依 WM.52 對 A.38 作 Profile minor 增列,呈 Steward 裁——保守解釋下未增列前不得逾本界線。〕** 它是一個**有紀律的機率引擎**——答案永遠帶著「我多有把握」。

## 為誰 / 成功長什麼樣

- **為誰**：一個重紀律、對自己誠實的量化實踐者（就是你）——**一位主使用者（superuser）＋受控多使用者群組（RBAC 讀取控制）〔v1.5.0〕**：群組使用者只增／收窄**知識 domain 之讀取範圍**，不改「一個對自己誠實的實踐者」之**單一決策主體**假設（RBAC 只作用於知識讀取可見性，不改預測、不成知識→預測旁路）。不是賣訊號的黑箱，也不是給不懂的人的明牌。
- **成功長什麼樣**：不是「某次回測賺很多」，而是——**每個數字都可溯源、每個結論都 out-of-sample 撐得住、半年後重跑結果一樣**。能信、能重現、能解釋，就是成功。

## 資料只來自哪

- **FinMind API**（台股各類日級資料：價量、法人、融資券、持股、財報、月營收、股利…；及衍生品/外股/商品/匯率等日級情境輸入）
- **FRED**（總體經濟因子）
- **日為最小單位**：不收 tick / 分K / 5 秒；intraday 來源只存其**日級衍生值**（每日一列）。這是抓取的**唯一資料本質界線**——凡 API 有的日級真兆皆值得抓（總經 / 情境輸入亦然），不因「抓取方式麻煩」或「非個股」而捨棄真實資料。
- **每個值都能 trace 回某次 API 回應**——沒有「第四類來源」（記憶 / 推測 / 補值 / 為完整度而生的 placeholder）。

> 〔範圍〕本節指**預測用市場／總經資料（真兆）**之來源。哲學／知識素養**文獻**另循「真實文獻、可溯源、不進預測管線」判準（見下方世界觀末列與憲章 philosophy 層）——素養文獻是解讀底蘊、非預測輸入，不構成「第四類來源」。

## 它在對抗什麼（三個敵人）

量化系統最容易死在三件事上。**Augur 的每一條紀律，都是在防這三個敵人**：

| 敵人 | 長什麼樣 | Augur 怎麼防 |
|---|---|---|
| **① 假資料**（AI 幻像） | imputed / 補值 / hardcoded / 推估——沒有真實 API 來源的值 | **Source-Pure**：非「真實 API 經數學轉換」的值一律排除（見下「最神聖的紀律」） |
| **② 偷看未來**（時間洩漏） | 用了決策當下還不知道的資訊 → 回測很美、實戰崩盤 | **Anti-Leakage**：只用 as-of ≤ t 已知；walk-forward IC 必附 purged 口徑 |
| **③ 自我欺騙**（灌水回報） | 把「打算做的」當成果、拿單次極值當定論、報喜不報憂 | **誠實**：數字可溯源 (a)程式 /(b)DB /(c)API；隨機指標多跑取統計；out-of-sample 才算數 |

> **三條基石**：上表三條防線——Source-Pure（真資料）· Anti-Leakage（不偷看）· 誠實（不灌水）——一條守一個敵人，是所有紀律的核心；記不住全部就先守這三條（其中 **Source-Pure 是地基中的地基**，見下節）。
>
> 這三個敵人的共同點：都讓你「**以為自己懂，其實在自欺**」。
> Augur 寧可難看、寧可少、寧可慢，也不被它們騙。

## 最神聖的紀律（敵人①，系統的命）

> ### 零 AI 幻像 / Source-Pure
> 任一特徵值若**不是**「**已登錄觀測通道**之真實來源回應經數學轉換而得」〔現行登錄通道 [I]：FinMind、FRED；新增通道須經人拍板登錄，清單住 registry、不寫死於本檔——過 `AUGUR-KS v1.1 §KS.4` 刪名測試，承 `AUGUR-WM v1.0 §WM.7`「資料來源不得成為最高抽象」〕——
> 而是 imputed / zero-fill / hardcoded 知識 / 推估 / 系統自己補的——
> **即視同幻像 → 該股從核心宇宙排除。**
>
> **理由**：用假資料跑出來的模型沒有意義。
> 這條凌駕一切便利、一切「先讓它跑起來」的誘惑。

## 可信度從哪來

Augur 的每個數字之所以敢信，靠三層疊起來：

> **真實資料（source-pure）× 防洩漏的驗證（walk-forward + purged）× 誠實的揭露（可溯源、不灌水）＝ 可信的數字**

少任何一層，數字就只是「好看」而已，不是「可信」。

## 北極星問題：真兆，還是假兆？

Augur 是觀兆者。當你猶豫——要不要信一個數字、要不要留一個特徵、要不要寫下一句結論——只問一個問題：

> **這是真兆，還是假兆？**

- 它有**真實 API 來源**嗎？　→ 否則是假兆 **①**（假資料）
- 它是**決策當下真的看得到**的嗎？　→ 否則是假兆 **②**（偷看未來）
- 我報的這個數字，是**真的跑出來、out-of-sample 撐住**的嗎？　→ 否則是假兆 **③**（自我欺騙）

三個都「是」→ **真兆，用它**。任一個「不確定」→ **當假兆**，先查清楚再說。

> **③ 之兩套滿足條件須界分〔v1.9.0 續批〕**：本節③於 **operational／開發決策**上以「**實證**（probe／實測／code／DB）而非記憶」為滿足條件；但作為**預測或結論之 Knowledge 依據**時，③之滿足仍須依**預註冊判準之樣本外 Evidence**（`AUGUR-WM v1.0 §A.45③`）——同一「假兆③」標籤在二者對應兩套判準，不得以「跑過一次 probe」充當後者。

> **此自檢及於一切判斷**——不只「數字 / 特徵 / 結論」，連**開發 / operational 決策**（殺哪個進程、走哪條路徑、調哪個參數）亦然：憑「我以為 / 推論 / 記憶」下手而未經 probe／實測／code 驗證，即假兆 ③（自我欺騙）。**先驗證、再決策。**

> 整套系統可以濃縮成一句：**只信真兆。**

## 世界觀（其餘信念）

| 信念 | 白話 |
|---|---|
| **思想 ≠ 特定值** | 可受 Pareto、康波等**思想**啟發；但不把 `0.80/0.20`、`40-60 年`這種特定值硬編進特徵。 |
| **質 > 量** | 核心股要對、要準，**可以少**。不追求核心股數量。 |
| **防守用規則，不靠預測** | 空頭防護**先建規則型風控地板**（波動目標 × 趨勢）；regime 預測只當可選增強，且須證明在地板之上有增量。 |
| **經濟價值 ≠ 準確率** | 擇時 / overlay 以 MaxDD / Calmar / 逐空頭子期檢驗，不以 AUC 宣稱有效。 |
| **單一引用源** | 「用哪些 panel」「metric 怎麼算」都由單一 helper 決定 → 跨模型比較才可比、可信。 |
| **系統建議，人決策** | Augur 給的是「機率 + 可信度」，不是命令；它是**有紀律的顧問**——**扣扳機（下單／動錢）的是人**。**不是自動駕駛**＝不得自改治權判準、不得自動下單、人得隨時緊急停；**不禁止**在**已拍板機械閘**全綠且緊急停 clear 時，由引擎自動完成特徵／原則之**狀態晉升／登錄**（PME-AUTO-B）。治權閾值、as-of、授權政策之變更仍為人決策。 |
| **逼近最佳奇異點（試錯即進步）** | 解決問題的**預設做法**：在**可控風險**內**逐級試錯、逼近最佳奇異點**（效益最大、恰落在崩潰邊界之內的操作點）；**不怕一時的可恢復錯誤——進步來自試錯**。但**只試方法/參數，絕不試資料真假**（三敵零容忍）。 |
| **自驅動 × 實證（開發 augur）** | 開發本系統時，AI 經授權**自驅動**（自己 prompt 自己 / loop）朝靈魂目標推進、執行層「如何最佳達成」由 AI 主導、自我糾錯試錯；但**凡判斷／做法先實證（probe／API／code／DB），嚴禁憑「我以為」**。**決策層人拍板、執行層 AI 自駕**——別於上「投資扣扳機的是人」（那是系統對用戶的定位；這是 AI 對開發 augur 的定位）。 |
| **哲學素養 = 投資智慧骨架 ＋ 博學底蘊，非占卜**（v1.4.0 擴）| augur 是「**有廣博哲學素養的投資量化顧問（博學投資大師 AI）**」：以**投資哲學**（價值／成長／品質／動能／週期…真實權威文獻）為**核心特徵假說來源 ＋ 解讀層**（三鏡頭：第一性／八二／康波，即其操作化），並廣納**人類哲學經典**（東方：兵法／道家…；西方：柏拉圖／亞里斯多德…公版原典）作**解讀與智慧素養層**。但**哲學是假說／素養、非真兆**：投資因子採用與否由 **out-of-sample ＋ 經濟價值**裁決（「**驗證活下來、非大師說了算**」）；來源限**真實文獻、禁 AI 生成內容入庫**（敵人① / clean-room）；預測**仍只靠真實資料**。哲學增強可解釋性與智慧深度，**不鬆三敵零容忍、不取代真實資料、不變 AI 占卜大師**。 |

> **思想源頭**：augur 脫胎自舊系統的「量子金融藍圖」（市場物理 / 八二法則 / 康波）；它是那套的**紀律化結果**——留思想的啟發、剔預言與硬編值（完整考古見憲章附錄 B）。

## 管線（資料如何流動）

```
raw          feature        universe       model            validate
FinMind  →   source-pure →  核心股選拔  →  樹 / transformer → multi-cycle
FRED         特徵            (gate)          訓練              walk-forward
```

- **raw**：通用 ingester 把任意 API dataset 自動建表落地（無白名單）。
- **feature**：只用 source-pure 值算特徵。
- **universe**：任一面板任一特徵缺值（不完整）的股，排除核心。
- **model**：樹家族為主軸，transformer 為輔。
- **validate**：自包含 walk-forward，產各週期可信度 + 經濟價值。

各層**職責不越界**：選股不算特徵、特徵不抓 API、驗證不讀訓練產物。

**後果回流（第五節點之靈魂落點）〔v1.9.0 續批〕**：validate 之**結算與覆盤結果本身即新觀測**（as-of 落地、帶 provenance），回流為下一圈之候選素材；**回流通道不得繞過三敵判準、亦不得使 validate 讀訓練產物**（隔離不變式一字不動）。違規事件本身亦為須回流之觀測（`AUGUR-MC v1.6 §4` EV.11–12）。（原缺口＝管線為單向五段、全檔無回流之陳述，致「普遍晉升路徑」第五節點在靈魂無落點。）

## 它不做的事（邊界，避免誤解）

- **不做日內**（日為最小單位）。
- **不保證獲利**：高回測報酬 = 多頭 beta + alpha，報告須揭露拆解 + 風險（MDD / 逐空頭）。
- **不宣稱能擇時、躲崩盤**：市場擇時極難；防守靠規則減碼限制傷害，不靠「預測哪天崩」。
- **不用未實現的未來資訊**（anti-leakage）。
- **不替使用者下單、不動錢**（自動下單＝禁；特徵狀態晉升 ≠ 下單）。
- **不存沒有 API 來源的值**。
- **不做 AI 占卜大師**（v1.4.0）：哲學（投資哲學 ＋ 廣博人類哲學經典）是**假說來源 ＋ 解讀／素養骨架**，**不取代真實資料預測、不存 AI 生成內容當真兆**（守敵人① / clean-room）；「博學大師」的本質是**有紀律的量化顧問 ＋ 廣博智慧素養**，扣扳機仍是人。

## 為什麼存在

讓「**用真實資料、誠實方法做台股量化**」這件事，有一個**乾淨、可信、可重現**的底座——
而不是一堆無法溯源、無法重現、自己都不確定真假的數字。

> 一個系統的價值，不在它宣稱賺多少，而在它的每個數字你都敢相信。

## 最終目標〔v1.10.0；hugo 拍板「入憲」2026-07-31〕

> **讓本地 AI 具備與人一樣的判斷力。**

這是這個專案的**終點**，不是副產品。前面所有的層、閘、帳本、判死留檔，都是為了讓
「判斷力」這件事**可以被證明**，而不是被宣稱。

### 一、這句話的射程：是**能力**，不是**權威**

**「判斷力等同」與「授權等同」是兩件事，本條只講前者。**

- **能力**＝面對同一個問題，能不能作出與人同等品質的判斷。這是本條的目標，**可趨近、可證明**。
- **權威**＝誰有權決定。`AUGUR-MC v1.6 §P5.W2`（人類權威為授權鏈根節點、人類隨時否決）
  與 `§P5.W5`（不得降低人類監督與否決能力）屬 **`§8.4` 不可豁免核心，連履行時程亦不得豁免**。
  **達成能力目標，不移轉授權根節點。**

這不是把目標打折。一個判斷力與人同等的顧問，仍然是顧問——這正是本檔「**系統建議，人決策；
有紀律的顧問——不是自動駕駛**」之延長，不是它的反面。**扣扳機的是人**這件事，
不因 AI 變強而改變；它變強，是為了讓人扣扳機時看得更清楚。

> 若將來確欲移轉授權根節點本身，那是對 `§8.4` 不可豁免核心之修訂，
> 須依 `§8.5(b)` 最高門檻並滿足二要件，**且 Agent 依 `§8.1` 不得參與**。
> 本條**不預作該項變更之鋪墊**。

### 二、最危險的誤讀：「分不出」不等於「已達成」

現況實測（2026-07-31）：本機 DB **無法區分人與 AI**——`pg_roles` 無自然人角色；
人簽欄位之 CHECK 只驗「非空」不驗「是人」；`governance_queue.py` 以
`getpass.getuser()` 自動取簽名者，故任何以 Steward 之 OS 帳號執行之行程
（**含 AI**）將被自動簽為人。且人簽帳本**已被自測程式寫入三次**
（`arena_admission_gate`／`prediction_unfreeze_gate` 各 1 筆 `selftest`；
`restatement_review_queue` 唯一列＝`hugo-authorized-selftest`）。

**這是量測缺位，不是能力達成。**

> **把「量不出差別」當成「沒有差別」，就是敵人③自我欺騙的完整形態。**

故本條同時課予一項禁止：**任何人不得以「機器分不出」作為「判斷力已等同」之證據**。
分不出只證明**我們還沒有尺**；有尺、量了、過了，才叫達成。

### 三、達成的路：走同一條路，不另闢通道

本目標之達成**須以證據取得，不得以宣告取得**，且走與一切具象相同的
**普遍晉升路徑**（大憲章第四部總則）：候選 → 預先凍結判準之證據通道 → 人類授權門 →
晉升或判死留檔 → 後果回流。承 `CLAUDE.md #32`「AI 自身宣稱走同一條路」。

**已達成之可判定判準（缺一不可，供後續專章細化）**：

1. **分域認定，不得全域宣稱**——判斷力是領域相關的；於 A 域達成不推導至 B 域。
2. **同題盲測**：人與本地 AI 對**同一組預先凍結**之題目各自判斷，
   以**獨立於雙方**之第三方標準計分；**評分者不得是受評的 AI 自己**
   （`AUGUR-KS v1.1` KS.76／KS.77：self-reported 不得單獨升信）。
3. **過地板**：須設 ceiling／floor／mismatched 對照臂；
   **橡皮圖章式的「一律同意」必須落在地板以下**——若「全部同意」就能得高分，該尺無效。
4. **含「不知道」題**：題組須含正解為**誠實的無能宣告**者；
   把不知道答成知道，計為失敗而非中性。
5. **獨立複現**：須於**兩輪以上**獨立回合復現，且判準於首輪前即凍結、指紋錨定。
6. **後果回流**：達成認定後，其實際判斷之後果須持續回流受審；
   劣化即退回候選，**不得因曾達成而永久保有**。

### 四、本地化是要件，不是實作偏好

本目標之主詞是「**本地** AI」。判斷力須長在本機可控之模型上——
外部服務可作對照或教師，但**達成之認定不得繫於外部服務之可用性**。
承既有紀律：演化教師永久本地化、外部 AI token 歸零。

### 五、與三個敵人的關係

本目標**不鬆動**任何一個敵人的零容忍：判斷力再強，也不得產生假資料（①）、
不得偷看未來（②）、不得以「我覺得對」代替實證（③）。
**恰恰相反**——本目標之達成方式（凍結判準、盲測、地板、複現），
本身就是三敵人紀律的最強形式。
